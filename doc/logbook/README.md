# Remontoire logbook

The dated, append-only record — builds, trials, smoke tests, measurements, suite-falsified claims. The doctrine
these entries settled lives distilled in `doc/design/`; this folder is the evidence trail. (Moved out of §11 when the
design doc was split, 2026-08-07; split from a single `doc/logbook.md` into one file per entry, 2026-11-03.
§-references resolve per the convention in CLAUDE.md.)

One entry per file, named `YYYY-MM-DD-NN-slug.md`: the date the entry records, a two-digit sequence keeping a day's
entries in the order they were written, and a short slug of the title. A new entry is a new file; entries are not
rewritten after the fact — a later finding that revises an earlier one gets its own entry and says so.
